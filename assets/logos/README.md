# Soliton logos

Horizontally mirrored continuous waveform, from the reference supplied by the user
on 24 October 2026. These six SVGs are the production sources for the interface,
the seven-size Windows icons and the notification icon fallback. The stroke was
reduced from 37 to 28 units in the path coordinate system to keep the loops apart
at small sizes.

| File | Palette | Background | Wave |
| --- | --- | --- | --- |
| `blue.svg` | Electric blue | `#315EF4` | `#FFFFFF` |
| `teal.svg` | Deep teal | `#086E75` | `#FFFFFF` |
| `violet.svg` | Violet | `#7544D8` | `#FFFFFF` |
| `copper.svg` | Copper | `#B65A32` | `#FFFFFF` |
| `graphite-mint.svg` | Graphite and mint (default) | `#23272F` | `#8BE0C0` |
| `ivory-ink.svg` | Ivory and ink | `#EEE6D7` | `#242F33` |

`Settings.app_icon` is independent of the theme and accent color. Windows resource
1 uses `graphite-mint.svg`; resources 2 to 7 follow `AppIcon::ALL`, in the order
of this table.
